## 想定シナリオ

DBの保守担当者が、インターネットから直接到達できるVMを増やさずにPostgreSQLへ接続する。担当者はAzure PortalでAzure Bastionのセッションを開き、プライベートIPだけを持つWindows JumpboxへRDP接続する。DBクライアントはJumpbox上で動かす。

PostgreSQL Flexible ServerはVNetの委任サブネットへ配置し、パブリックネットワークアクセスを無効にする。JumpboxからDBのFQDNを名前解決して接続できることまでを、この学習用構成で確認する。

## 設計判断

### ADR-001: 管理セッションをAzure Bastionへ集める

- 背景: JumpboxのRDPを公開すると、管理用VMの受信面がインターネットへ出る。
- 決定: Standard SKUのAzure Bastionを専用サブネットに配置し、JumpboxのNICにはPublic IPを割り当てない。JumpboxのNSGはBastionサブネットからのRDPとSSHだけを許可し、それ以外の受信を拒否する。
- 影響: Public IPはBastionにだけ関連付けられる。BastionのNSGを管理する場合は、Portal接続、サービス制御、ヘルスプローブに必要なルールを維持する必要がある。

### ADR-002: PostgreSQL Flexible ServerをVNetへ統合する

- 背景: DBに接続できるクライアントをVNet内へ限定する。
- 決定: PostgreSQL用サブネットを`Microsoft.DBforPostgreSQL/flexibleServers`へ委任し、Flexible Serverに委任サブネットとPrivate DNS Zoneを渡す。JumpboxのNSGはDBサブネット宛てのTCP 5432を許可する。
- 影響: Private DNS ZoneをVNetへリンクしなければ、JumpboxはFlexible ServerのFQDNを解決できない。ネットワーク到達性と名前解決を別々に確認する。

## コスト試算

常設時の主要リソースの概算は月額USD 473.08である。Japan East、従量課金、730時間/月を前提に、出典TerraformのSKU（Bastion Standard、Windows `Standard_B2ms`、PostgreSQL General Purpose `D2s_v3`・2 vCore、ストレージ32GiB）に合わせて計算している。契約形態、為替、利用量によって請求額は変わる。

| Azure Bastion Standard | USD 211.70 |
| Windows Jumpbox `Standard_B2ms` | USD 85.41 |
| PostgreSQL General Purpose `D2s_v3`、2 vCore | USD 171.55 |

## セキュリティと運用

### 実装済みのこと

- BastionだけにStandard Public IPを関連付け、JumpboxのNICにはPublic IPを定義しない。
- JumpboxのNSGはBastionサブネットからのRDP/SSHとDB宛てのTCP 5432を明示し、その他の受信を拒否する。
- Flexible Serverは委任サブネットとPrivate DNS Zoneを使い、パブリックネットワークアクセスを無効にする。バックアップ保持は7日、ストレージ自動拡張は有効にする。
- JumpboxとDBの管理者パスワードはTerraformで生成し、root outputには出力しない。

### 確認と削除

1. `main/`で`terraform apply`を実行する。
2. Azure PortalからBastionを開き、JumpboxのプライベートIPへRDP接続する。
3. JumpboxでDBクライアントを用意し、Flexible ServerのFQDNを名前解決できることとTCP 5432で接続できることを確認する。
4. 学習後は`main/`で`terraform destroy`を実行し、Bastion、VM、DBを削除する。

## 学習スコープと本番化への差分

この構成は、Bastionを使った管理接続、Jumpboxの受信制限、VNet統合したPostgreSQLの到達性を扱う。Azure RBACなどのテナント権限設計、監視、可用性、災害復旧はTerraformに定義していないため、このケースの範囲には含めない。

本番化では、管理者の権限と操作監査、障害検知、バックアップ復元手順、可用性と復旧目標を別途設計する。BastionのPublic IPとJumpboxの公開を混同せず、Portalの管理経路、VMへのRDP、DBへの名前解決とTCP接続を分けて検証する。
